# Web Development Project 6 - *Today's News Headlines - version 2*

Submitted by: **Mingzhu Shi**

This web app: **Top News - Version 2**

Time spent: **12** hours spent in total
- fetch latest news data from newsapi and display news information in news cards
- search news by categories or keywords
- dashboard for easy navigation
- fetch stock market data from Alpha Vantage Api and include close data for latest 30 days for S&P 500, Dow Jones and Nasdaq
- create line charts using Recharts

## Required Features

The following **required** functionality is completed:

- [x] **Clicking on an item in the list view displays more details about it**
  - Clicking on an item in the dashboard list navigates to a detail view for that item
  - Detail view includes extra information about the item not included in the dashboard view
  - The same sidebar is displayed in detail view as in dashboard view
  - *To ensure an accurate grade, your sidebar **must** be viewable when showing the details view in your recording.*
- [x] **Each detail view of an item has a direct, unique URL link to that item’s detail view page**
  -  *To ensure an accurate grade, the URL/address bar of your web browser **must** be viewable in your recording.*
- [x] **The app includes at least two unique charts developed using the fetched data that tell an interesting story**
  - At least two charts should be incorporated into the dashboard view of the site
  - Each chart should describe a different aspect of the dataset
